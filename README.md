# CrashCross

Interactive website for the IT 462 Exploratory Data Analysis project (Group B8, Dhirubhai Ambani
University): **police-reported crashes in Allegheny County, Pennsylvania, 2004–2024**.

- **Research presentation** — Overview, the six report chapters (Introduction, Data Cleaning,
  Visualization, Feature Engineering, Model Fitting, Conclusion & Future Scope), Appendices, the
  original PDF in a page-turning reader, and Resources. Figures and tables are rebuilt from the
  verified analysis export `v6-export-20261120-08`; nothing re-runs the notebook or the models.
- **EDAgent** — a separate, general-purpose EDA tool for a user's own CSV/TSV/JSON/JSONL/XLSX file:
  overview and quality checks, configurable charts, optional dataset-grounded AI chat, and
  HTML/JSON/ZIP export.

## Repository layout

| Path | What it is |
| --- | --- |
| `web/` | React 18 + Vite + TypeScript + Tailwind + Plotly site (static; deploy to Vercel or any static host) |
| `web/public/data/` | Published research data, generated by `scripts/build_site_data.py` (committed) |
| `api/` | FastAPI service for EDAgent only (uploads, charts, chat, exports); no database |
| `scripts/build_site_data.py` | Copies publishable files from the export run into `web/public/data` with hashes |
| `scripts/verify_site_data.py` | Verifies hashes, access classes, report values and frontend data references |
| `docs/` | Architecture, data mapping, features, EDAgent, deployment, validation, handoff, progress |
| `analysis/` | **Not committed.** Local copy of the immutable notebook and export package (input only) |

## Quick start (local)

Prerequisites: Node.js 18+ (tested 22.16), Python 3.11+ (tested 3.13.7).

```powershell
# Website
cd web; npm ci; npm run dev            # http://localhost:5173 (proxies /api to :8000)
```

```powershell
# EDAgent API (separate terminal, from the repo root)
python -m venv api/.venv; api/.venv/Scripts/python -m pip install -r api/requirements-dev.txt
api/.venv/Scripts/python -m uvicorn app.main:app --app-dir api --port 8000
```

The research pages work without the API. Copy `.env.example` values into your environment (or
`api/.env` via your process manager) to configure limits and the optional provider keys (`ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `XAI_API_KEY`).

## Rebuilding and verifying research data

Only needed if the export package changes. Place the completed export under `analysis/`, then:

```powershell
python scripts/build_site_data.py --export analysis/v6-export-20261120-08
python scripts/verify_site_data.py
```

The build refuses runs without `COMPLETE.json`, runs with `INCOMPLETE.json`, or a manifest whose
hash differs from `COMPLETE.json`. Only `public_candidate_*` and `aggregate_review` files are copied.

## Tests

```powershell
api/.venv/Scripts/python -m pytest api/tests -q    # 24 API tests
cd web; npm run build                                # typecheck + production build
```
